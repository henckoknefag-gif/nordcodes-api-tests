# API-тесты NORD/CODES

Здесь 18 тестов: вход, действия, выход и запросы с неверными данными.

Отчет за **18.10.2026**: [посмотреть Allure в браузере](https://henckoknefag-gif.github.io/nordcodes-api-tests/).

## Что понадобится

- **IntelliJ IDEA** - программа, в которой можно открыть проект и запустить тесты.
- **JDK 17** - набор для запуска программ на Java. Его можно скачать прямо из IDEA по шагам ниже.
- **Интернет** - для первой загрузки проекта, библиотек и программы для отчета.
- **Браузер** - чтобы посмотреть отчет.

Приложение из задания уже лежит в папке `app`. Устанавливать его отдельно не нужно.

## Зависимости

Зависимости - это готовые библиотеки, которые используются в тестах.
Их список и версии указаны в `pom.xml`:

- **JUnit 5** запускает тесты и проверяет результаты.
- **WireMock** отвечает вместо внешнего сервиса. В тестах можно задать его ответ.
- **Allure** собирает результаты тестов в отчет.
- **Jackson** читает ответы приложения в формате JSON.
- **Awaitility** ждет, пока приложение будет готово к работе.
- **Google Error Prone Annotations** добавляет пометки в коде, например о том,
  что результат метода нужно использовать.

Все это скачивает **Maven**. Устанавливать его вручную не нужно: в проекте есть
**Maven Wrapper**, который загрузит нужную версию. При открытии проекта и первом
запуске Maven скачает библиотеки, Spotless и Checkstyle для проверки оформления кода.
Spotless форматирует код, а Checkstyle проверяет в том числе ограничение в 100 символов на строке.
При первом запуске отчета Maven также скачает программу Allure.

## Запуск в IDEA

1. Скачать проект: на странице репозитория нажать **Code -> Download ZIP** и распаковать архив.
   Если папка проекта уже есть на компьютере, перейти к следующему шагу.
2. В IDEA через **File -> Open** открыть папку проекта, в которой лежит `pom.xml`.
   Если IDEA предложит открыть ее как Maven-проект, подтвердить.
3. В **File -> Project Structure -> Project -> SDK** выбрать JDK 17.
   Если JDK еще не установлен, нажать **Add SDK -> Download JDK** и скачать версию **17**.
4. В **Settings -> Build, Execution, Deployment -> Build Tools -> Maven**
   выбрать **Use Maven wrapper**. В подразделе **Runner** указать **JRE: Project SDK**.
5. Дождаться загрузки библиотек. Если она не началась, нажать
   **Reload All Maven Projects** в окне Maven справа.

В списке запуска сверху выбрать **Все 18 проверок** и нажать **Run**.
Приложение и WireMock запустятся сами, а после тестов остановятся.

Чтобы посмотреть результаты, запустить **Отчет Allure** из того же списка.
Он откроется в браузере. Внутри можно выбрать тест и посмотреть, что не прошло.
После просмотра нажать **Stop** в IDEA, чтобы остановить сервер отчета.

В отчете от 18.10.2026 проходят 16 проверок из 18. Две проверки не проходят:
приложение отклоняет токены с буквами G-Z, хотя задание их разрешает.
Подробности есть в Allure. Отдельный файл с описанием бага не создавал.

При использовании AdGuard отключить **Фильтровать localhost** в
**Настройки -> Настройки приложения -> Расширенные настройки**.
Эта настройка может мешать запросам между приложением и WireMock и приводить к ошибке 500.
При запуске и отладке я столкнулся с такими падениями. После отключения этой настройки они исчезли.

## Файлы

Тесты лежат в `src/test/java/nordcodes/qa/api/tests`:
в `positive` проверяется работа с правильными данными, в `negative` - отказы при ошибках.

В `nordcodes/qa/api` находятся классы входа и действий пользователя.
В `nordcodes/qa` лежат `client` для отправки запросов, `assertions` для проверки ответов
и `environment` для запуска приложения и настройки внешнего сервиса.
Файл приложения лежит в `app`, а результаты и журналы запусков сохраняются в `target`.
Готовый отчет лежит в `docs/index.html`. Его можно открыть в браузере после скачивания проекта.
